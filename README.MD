# Gerenciador de Configurações de Usuário

Um sistema simples para gerenciar configurações de usuários, desenvolvido em Python.

Este projeto foi criado como parte da minha jornada por meio dos exercícios do freeCodeCamp.

## Funcionalidades

- Adicionar novas configurações.
- Atualizar configurações existentes.
- Excluir configurações.
- Visualizar todas as configurações cadastradas.
- Impedir o cadastro de configurações duplicadas.
- Padronizar chaves e valores utilizando letras minúsculas.

## Tecnologias utilizadas

- Python 3

## Conceitos praticados

- Dicionários (`dict`).
- Tuplas (`tuple`).
- Funções.
- Estruturas condicionais (`if` e `else`).
- Laços de repetição (`for`).
- Métodos de manipulação de strings.
- Manipulação de dicionários.

## Objetivo do projeto

Praticar os fundamentos da linguagem Python por meio do desenvolvimento de um pequeno sistema de gerenciamento de preferências de usuários.
